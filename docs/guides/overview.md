# MathZig Overview

MathZig is a high-performance math expression engine written in Zig. It parses expressions, compiles them to bytecode, and executes them on a native VM with SIMD-aware paths. The same pipeline feeds WebAssembly (interpreter module + expression/graph AOT) and TypeScript hosts (FFI and WASM).

**Product surfaces**

- Browser console + graph editor: `apps/console` (SolidJS)
- Progress / regression dashboard: `apps/progress`
- Terminal UI: `src/tui` → `zig build run`
- CLI REPL / compiler: `src/main.zig` → `zig-out/bin/mathzig`

---

## Key capabilities

| Area | What exists today |
|------|-------------------|
| **Expression compile** | Tokenizer + AST → bytecode (`parser/`, `vm/bytecode.zig`) |
| **VM** | Bytecode interpreter with fast paths / SIMD batch hooks (`vm/vm.zig`) |
| **Types** | number, complex, matrix, unit, series, record, boolean, string, … (`core/value.zig`) |
| **AOT WASM** | Expression and node modules (`src/wasm/`); fused graphs via `compile-graph` |
| **Graphs** | Multi-module `GraphRunner` (editor hot path) + fused one-module export |
| **FFI / TS** | Generated C-ABI + `src/ts/mathzig.ts`, WASM wrapper, graph TS runners |
| **Time series / ODE** | Indicators, joins, resampling, ODE solvers under `functions/` + `timeseries/` |
| **Parity** | JSON vectors run on `zig_vm`, `ts_ffi`, `ts_wasm_vm`, `wasm_aot` |

## Architecture

```text
Expression string
      │
      ▼
 Parser / Compiler  ──►  CompiledExpr (bytecode)
      │                         │
      │                         ├──► Native VM  (zig_vm)
      │                         │
      │                         ├──► FFI (libmathzig) ──► ts_ffi
      │                         │
      │                         └──► WASM interpreter module ──► ts_wasm_vm
      │
      └──► WASM AOT compiler ──► freestanding .wasm ──► wasm_aot / hosts

GraphDefinition
      │
      ├── multi-module: one wasm per compute node ──► GraphRunner
      └── fused: one wasm for whole graph ──► compile-graph / FusedGraphRunner
```

Zig VM is the **source of truth**. Other backends must match it on shared parity cases.

## Evaluation flow

### 1. Compile (conceptually)

```ts
// TypeScript FFI sketch (src/ts/mathzig.ts)
const ctx = MathZig.create();
const xIdx = ctx.addVariableIndexed("x", 0);
const compiled = ctx.compile("x * 0.5 + 2.0");
```

Bytecode shape (illustrative):

```text
load_var(0) → push_const(0.5) → mul → push_const(2.0) → add → halt
```

### 2. Execute

```ts
ctx.setByIndex(xIdx, 10);
const result = compiled.evaluateFast(); // 7.0
```

### 3. AOT

```bash
./zig-out/bin/mathzig compile -i expr.mz -o out.wasm
./zig-out/bin/mathzig compile -i expr.mz -o out.wasm --standalone
./zig-out/bin/mathzig compile-graph -i graph.json -o out.wasm
```

Consumption guide: [`wasm_aot_usage.md`](./wasm_aot_usage.md). Host demos: [`../../hosts/README.md`](../../hosts/README.md).

## Supported types (runtime)

- **Numbers** — f64  
- **Complex** — re + im  
- **Matrices** — dense, SIMD-aligned storage  
- **Units** — SI dimensions + conversion  
- **Series** — time series (host handle and linear-memory AOT modes)  
- **Records** — named fields  
- **Booleans / strings** — tagged values  

Operations cover arithmetic, comparison, logical/bitwise, math builtins, matrix ops, unit conversion, timeseries indicators, and ODE integration (tier support varies by backend / standalone AOT).

## Quick commands

```bash
# Native
export PATH="$PWD/tools/macos-sdk-shim:$PATH"   # macOS if needed
zig build
zig build repl
zig build test
zig build vm-baseline

# Daily correctness + perf + progress
bun run mz

# Product UI
zig build -Dtarget=wasm32-freestanding -Doptimize=ReleaseSmall
cp zig-out/bin/mathzig_wasm.wasm apps/console/public/
bun install --cwd apps/console && bun run --cwd apps/console dev

# Progress UI (after mz)
cd apps/progress && bun run dev
```
